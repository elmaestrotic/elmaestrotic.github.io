Ejercicios de Haskell - Enunciado y Solución

1. Suma de enteros

📝 Enunciado: Crea una función llamada suma que reciba dos enteros y devuelva su suma.

suma :: Int -> Int -> Int
suma x y = x + y

2. Suma de flotantes

📝 Enunciado: Crea una función suma que reciba dos números decimales (Float) y devuelva el resultado.

suma :: Float -> Float -> Float
suma x y = x + y

3. Saludo simple con nombre

📝 Enunciado: Escribe una función saludo que reciba un nombre y retorne un mensaje como "Hola Alexander".

saludo :: String -> String
saludo x = "Hola " ++ x

4. Saludo con nombre y apellido

📝 Enunciado: Escribe una función que reciba nombre y apellido y retorne un mensaje como "Hola Alexander Narváez".

saludo :: String -> String -> String
saludo x y = "Hola " ++ x ++ " " ++ y

5. Saludo con edad (con show)

📝 Enunciado: Crea una función saludo que reciba un nombre y una edad (Int) y devuelva un mensaje como "Hola Alexander, tienes 35 años".

saludo :: String -> Int -> String
saludo x y = "Hola " ++ x ++ ", tienes " ++ show y ++ " años"

6. Mostrar valor booleano (con show)

📝 Enunciado: Crea una función mensaje que reciba un valor booleano y diga "¿Está activo? True" o "¿Está activo? False".

mensaje :: Bool -> String
mensaje b = "¿Está activo? " ++ show b

7. Estado del alumno con nota

📝 Enunciado: Escribe una función estadoAlumno que reciba un nombre y una nota (Float) y diga "María obtuvo 4.5 en el examen".

estadoAlumno :: String -> Float -> String
estadoAlumno nombre nota = nombre ++ " obtuvo " ++ show nota ++ " en el examen"

8. Evaluar si aprueba con if-then-else

📝 Enunciado: Crea una función evaluarnota que reciba una nota (Float) y devuelva True si es mayor o igual a 3.0, False si no.

evaluarnota :: Float -> Bool
evaluarnota nota = if nota >= 3.0 then True else False

9. Evaluar si aprueba con guardas

📝 Enunciado: Reescribe la función evaluarnota usando guardas en lugar de if-then-else.

evaluarnota :: Float -> Bool
evaluarnota nota
  | nota >= 3.0 = True
  | otherwise = False

10. Evaluación con 3 niveles de resultado

📝 Enunciado: Crea una función evaluar que reciba una nota (Float) y devuelva:

  • "Excelente" si la nota es mayor o igual a 4.5
  • "Aprobó" si es mayor o igual a 3.0
  • "Reprobó" en cualquier otro caso

evaluar :: Float -> String
evaluar nota
  | nota >= 4.5 = "Excelente"
  | nota >= 3.0 = "Aprobó"
  | otherwise = "Reprobó"
