Ejercicios de Expresiones Lambda en Java

1. ¿Cuál es el operador lambda?

📝 Enunciado: Identifique el operador utilizado para definir una expresión lambda en Java.

El operador lambda es ->.

2. ¿Qué es una interfaz funcional?

📝 Enunciado: Defina qué es una interfaz funcional en el contexto de Java.

Es una interfaz que contiene un único método abstracto.

3. ¿Cómo se relacionan las interfaces funcionales y las expresiones lambda?

📝 Enunciado: Explique la relación entre las interfaces funcionales y las expresiones lambda en Java.

Las expresiones lambda proporcionan una implementación del método abstracto definido por la interfaz funcional. La interfaz funcional define el tipo de destino para la lambda.

4. ¿Cuáles son los dos tipos generales de expresiones lambda?

📝 Enunciado: Identifique los dos tipos principales de expresiones lambda en Java y describa sus características.

Los dos tipos son:

  • Lambdas de expresión: Especifican una única expresión cuyo valor se devuelve.
  • Lambdas de bloque: Contienen un bloque de código y su valor se especifica con una instrucción return.

5. Expresión lambda para rango

📝 Enunciado: Muestre una expresión lambda que devuelva true si un número está entre 10 y 20, inclusive.

interface MyTest {
    boolean testing(int n);
}
MyTest inRange = n -> n >= 10 && n <= 20;
System.out.println("¿15 está en rango? " + inRange.testing(15)); // true
System.out.println("¿5 está en rango? " + inRange.testing(5));   // false

6. Interfaz funcional para lambda

📝 Enunciado: Cree una interfaz funcional llamada MyTest con un método abstracto testing() que admita la expresión lambda creada en la pregunta anterior.

interface MyTest {
    boolean testing(int n);
}

7. Lambda de bloque para factorial

📝 Enunciado: Cree una lambda de bloque que calcule la factorial de un entero usando la interfaz NumericFunc. Demuestre su uso.

interface NumericFunc {
    int func(int n);
}
public class Main {
    public static void main(String[] args) {
        NumericFunc factorial = n -> {
            int result = 1;
            for (int i = 1; i <= n; i++) {
                result *= i;
            }
            return result;
        };
        System.out.println("El factorial de 5 es: " + factorial.func(5)); // 120
    }
}

9. Lambda para eliminar espacios

📝 Enunciado: Cree una lambda que elimine todos los espacios de una cadena y devuelva el resultado. Demuestre su uso con la interfaz StringFunc.

interface StringFunc {
    String changeStr(String s);
}
public class Main {
    public static void main(String[] args) {
        StringFunc removeSpaces = s -> s.replaceAll("\\s", "");
        System.out.println("Resultado: " + removeSpaces.changeStr("Hola Mundo")); // HolaMundo
    }
}

10. Variables locales en lambdas

📝 Enunciado: ¿Puede una expresión lambda usar una variable local? En caso afirmativo, ¿qué restricción debe cumplir?

Sí, una expresión lambda puede usar una variable local siempre que sea efectivamente final (es decir, su valor no cambia después de su inicialización).

11. Excepciones en lambdas

📝 Enunciado: Si una expresión lambda genera una excepción comprobada, ¿debe el método abstracto de la interfaz funcional incluir una cláusula throws? ¿Verdadero o falso?

Verdadero. Si una lambda genera una excepción comprobada, el método abstracto de la interfaz funcional debe declarar esa excepción con una cláusula throws.

12. ¿Qué es una referencia de método?

📝 Enunciado: Defina qué es una referencia de método en Java.

Es una forma de hacer referencia a un método sin ejecutarlo, permitiendo usarlo como una instancia de una interfaz funcional.

13. Instancia de interfaz funcional

📝 Enunciado: Explique qué ocurre al evaluar una referencia de método en el contexto de una interfaz funcional.

Al evaluarse, una referencia de método crea una instancia de la interfaz funcional proporcionada por su contexto de destino.

14. Referencia a método estático

📝 Enunciado: Dada la clase MyClass con un método estático myStaticMethod(), indique cómo especificar una referencia de método a myStaticMethod().

class MyClass {
    static void myStaticMethod() { System.out.println("Método estático"); }
}
interface MyFunc {
    void func();
}
public class Main {
    public static void main(String[] args) {
        MyFunc ref = MyClass::myStaticMethod;
        ref.func(); // Imprime: Método estático
    }
}

15. Referencia a método de instancia

📝 Enunciado: Dada la clase MyClass con el método de instancia myInstMethod() y un objeto mcObj de MyClass, indique cómo crear una referencia a myInstMethod().

class MyClass {
    void myInstMethod() { System.out.println("Método de instancia"); }
}
interface MyFunc {
    void func();
}
public class Main {
    public static void main(String[] args) {
        MyClass mcObj = new MyClass();
        MyFunc ref = mcObj::myInstMethod;
        ref.func(); // Imprime: Método de instancia
    }
}

16. Referencia a constructor

📝 Enunciado: Explique cómo se especifica una referencia de constructor en Java, usando MyClass como ejemplo.

class MyClass {
    MyClass() { System.out.println("Constructor llamado"); }
}
interface MyFunc {
    MyClass create();
}
public class Main {
    public static void main(String[] args) {
        MyFunc ref = MyClass::new;
        ref.create(); // Imprime: Constructor llamado
    }
}
