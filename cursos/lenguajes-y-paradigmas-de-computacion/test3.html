Ejercicios Avanzados de Listas en Haskell - Enunciado y Solución

1. Construir una lista con cons

📝 Enunciado: Crea una función construirLista que tome un entero n y construya una lista con los números de 1 a n usando el operador cons (:).

construirLista :: Int -> [Int]
construirLista n = go n []
  where
    go 0 xs = xs
    go n xs = go (n-1) (n : xs)

2. Extraer elemento por índice

📝 Enunciado: Escribe una función obtenerElemento que use el operador !! para devolver el elemento en la posición n de una lista de enteros. Maneja el caso de índice inválido devolviendo Nothing.

obtenerElemento :: [Int] -> Int -> Maybe Int
obtenerElemento xs n
  | n < 0 || n >= length xs = Nothing
  | otherwise = Just (xs !! n)

3. Verificar pertenencia

📝 Enunciado: Crea una función contiene que use elem para verificar si un carácter dado está en una lista de caracteres y devuelva un mensaje como "El carácter 'a' está en la lista".

contiene :: Char -> [Char] -> String
contiene c xs
  | elem c xs = "El carácter '" ++ [c] ++ "' está en la lista"
  | otherwise = "El carácter '" ++ [c] ++ "' no está en la lista"

4. Tomar primeros elementos

📝 Enunciado: Escribe una función tomarN que use take para devolver los primeros n elementos de una lista de cadenas. Si n es mayor que la longitud de la lista, devuelve la lista completa.

tomarN :: Int -> [String] -> [String]
tomarN n xs = take n xs

5. Eliminar primeros elementos

📝 Enunciado: Crea una función descartarN que use drop para eliminar los primeros n elementos de una lista de enteros. Si n es mayor que la longitud de la lista, devuelve una lista vacía.

descartarN :: Int -> [Int] -> [Int]
descartarN n xs = drop n xs

6. Combinar listas en pares

📝 Enunciado: Escribe una función combinarListas que use zip para combinar dos listas (una de enteros y otra de cadenas) en una lista de tuplas. Devuelve una lista vacía si alguna de las listas está vacía.

combinarListas :: [Int] -> [String] -> [(Int, String)]
combinarListas xs ys
  | null xs || null ys = []
  | otherwise = zip xs ys

7. Longitud de una lista

📝 Enunciado: Crea una función longitudLista que use length para devolver un mensaje como "La lista tiene 5 elementos" para una lista de cualquier tipo.

longitudLista :: [a] -> String
longitudLista xs = "La lista tiene " ++ show (length xs) ++ " elementos"

8. Invertir una lista

📝 Enunciado: Escribe una función invertirLista que use reverse para invertir una lista de flotantes y devuelva un mensaje indicando si la lista invertida es igual a la original (para verificar palíndromos).

invertirLista :: [Float] -> String
invertirLista xs
  | xs == reverse xs = "La lista invertida es igual a la original: " ++ show (reverse xs)
  | otherwise = "La lista invertida es: " ++ show (reverse xs)

9. Ciclo de lista

📝 Enunciado: Crea una función cicloN que use cycle y take para generar una lista con los primeros n elementos de una lista cíclica basada en una lista de entrada de enteros.

cicloN :: Int -> [Int] -> [Int]
cicloN n xs
  | null xs = []
  | otherwise = take n (cycle xs)

10. Aplicación parcial con cons

📝 Enunciado: Escribe una función agregarPrefijo que use aplicación parcial con el operador cons (:) para agregar un prefijo fijo (por ejemplo, 0) a una lista de enteros, y devuelva la lista resultante.

agregarPrefijo :: [Int] -> [Int]
agregarPrefijo = (0:)
