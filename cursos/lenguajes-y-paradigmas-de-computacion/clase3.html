Introducción a Haskell

Haskell es un lenguaje puramente funcional que te invita a explorar cálculos como funciones matemáticas. En lugar de secuencias de tareas, aquí definimos "qué son las cosas" con elegancia y precisión. ¡Un viaje fascinante te espera! 🌟

Funciones por Defecto

Haskell incluye funciones poderosas listas para usar. Exploremos algunas:

ghci> succ 9
10
ghci> min 9 10
9
ghci> max 100 101
101
ghci> sum [1, 2, 3, 4]
10
ghci> product [2, 3, 4]
24

succ devuelve el sucesor, min y max comparan valores, sum suma listas, y product multiplica elementos. ¡Juega con ellas en ghci! 💡

Creación y Carga de Scripts

Crea tus propios scripts en archivos .hs. Por ejemplo, guarda esto en miScript.hs:

-- miScript.hs
doble x = x * 2
triple x = x * 3
saludo = "¡Hola, Haskell!"

Cárgalo en ghci con :load miScript.hs o :l miScript.hs. Recarga con :r. ¡Invoca tus funciones así!

ghci> :l miScript.hs
*Main> doble 5
10
*Main> triple 5
15
*Main> saludo
"¡Hola, Haskell!"
*Main> :r
*Main> doble 10
20

Agrega un main para ejecutar scripts directamente:

-- miScriptConMain.hs
main :: IO ()
main = do
putStrLn "Doble de 5:"
print (doble 5)
putStrLn "Triple de 5:"
print (triple 5)

doble x = x * 2
triple x = x * 3

Compílalo con ghc miScriptConMain.hs y ejecuta ./miScriptConMain para ver la magia. 🌟

Más Ejemplos de Funciones

Profundicemos en funciones con declaraciones de tipo. En Haskell, los tipos son clave:

-- Declaración de tipo explícita
areaCirculo :: Float -> Float
areaCirculo r = 3.14159 * r * r

esPar :: Int -> Bool
esPar x = x `mod` 2 == 0

-- Script: misFunciones.hs
factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

-- Carga y uso
ghci> :l misFunciones.hs
*Main> areaCirculo 5
78.53975
*Main> esPar 4
True
*Main> factorial 5
120

El main con do permite secuencias de E/S:

-- mainEjemplo.hs
main :: IO ()
main = do
putStrLn "Factorial de 5:"
print (factorial 5)
putStrLn "Área de círculo (r=5):"
print (areaCirculo 5)

Compila con ghc mainEjemplo.hs y ejecuta ./mainEjemplo. ¡Explora y crea! 🎉
