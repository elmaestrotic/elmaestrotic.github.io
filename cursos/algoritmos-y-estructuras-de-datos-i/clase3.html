Introducción a Estructuras de Datos

×

Las estructuras de datos son formas específicas de organizar y almacenar datos en una computadora para que puedan ser utilizados de manera eficiente.

🎯 Objetivos principales:

  • Optimizar el uso de memoria
  • Facilitar el acceso y manipulación de datos
  • Mejorar la eficiencia de algoritmos
  • Resolver problemas computacionales específicos
💡 Importancia:

La elección correcta de una estructura de datos puede reducir significativamente la complejidad temporal y espacial de un algoritmo.

Listas Enlazadas

×

Una lista enlazada es una estructura de datos lineal donde los elementos (nodos) se almacenan en secuencia, pero no necesariamente en ubicaciones contiguas de memoria.

🏗️ Componentes de un nodo:

  • Dato: La información almacenada
  • Puntero/Referencia: Dirección del siguiente nodo
#include <iostream> using namespace std; struct Nodo { int dato; Nodo* siguiente; // Constructor del nodo Nodo(int valor) : dato(valor), siguiente(nullptr) {} }; class ListaEnlazada { private: Nodo* cabeza; public: // Constructor de la lista ListaEnlazada() : cabeza(nullptr) {} // Insertar al inicio de la lista - O(1) void insertarAlInicio(int dato) { Nodo* nuevoNodo = new Nodo(dato); nuevoNodo->siguiente = cabeza; cabeza = nuevoNodo; } // Insertar al final de la lista - O(n) void insertarAlFinal(int dato) { Nodo* nuevoNodo = new Nodo(dato); if (cabeza == nullptr) { cabeza = nuevoNodo; return; } Nodo* actual = cabeza; while (actual->siguiente != nullptr) { actual = actual->siguiente; } actual->siguiente = nuevoNodo; } // Eliminar un nodo con valor específico - O(n) bool eliminar(int dato) { if (cabeza == nullptr) return false; // Si el nodo a eliminar es la cabeza if (cabeza->dato == dato) { Nodo* temp = cabeza; cabeza = cabeza->siguiente; delete temp; return true; } // Buscar el nodo a eliminar Nodo* actual = cabeza; while (actual->siguiente != nullptr) { if (actual->siguiente->dato == dato) { Nodo* temp = actual->siguiente; actual->siguiente = actual->siguiente->siguiente; delete temp; return true; } actual = actual->siguiente; } return false; } // Mostrar todos los elementos de la lista void mostrar() { Nodo* actual = cabeza; while (actual != nullptr) { cout << actual->dato << " -> "; actual = actual->siguiente; } cout << "NULL" << endl; } // Destructor - libera toda la memoria ~ListaEnlazada() { while (cabeza != nullptr) { Nodo* temp = cabeza; cabeza = cabeza->siguiente; delete temp; } } };

🔍 Tipos de Listas Enlazadas:

  • Simple: Cada nodo apunta al siguiente
  • Doble: Cada nodo tiene punteros al anterior y siguiente
  • Circular: El último nodo apunta al primero
Operación Complejidad Temporal Descripción
Inserción al inicio O(1) Constante, muy eficiente
Inserción al final O(n) Requiere recorrer toda la lista
Búsqueda O(n) Puede requerir recorrer toda la lista
Eliminación O(n) Primero buscar, luego eliminar
✅ Ventajas:
  • Tamaño dinámico
  • Inserción/eliminación eficiente al inicio
  • Uso eficiente de memoria
❌ Desventajas:
  • No acceso aleatorio
  • Memoria adicional para punteros
  • No cache-friendly

Colas (Queues)

×

Una cola es una estructura de datos que sigue el principio FIFO (First In, First Out). El primer elemento en entrar es el primero en salir.

🔄 Operaciones principales:

  • Enqueue: Agregar un elemento al final
  • Dequeue: Remover el elemento del frente
  • Front/Peek: Ver el elemento del frente sin removerlo
  • IsEmpty: Verificar si la cola está vacía
#include <iostream> #include <stdexcept> using namespace std; template<typename T> class Cola { private: struct Nodo { T dato; Nodo* siguiente; // Constructor del nodo Nodo(T valor) : dato(valor), siguiente(nullptr) {} }; Nodo* frente; // Puntero al primer elemento Nodo* final; // Puntero al último elemento int tamaño; // Número de elementos public: // Constructor de la cola Cola() : frente(nullptr), final(nullptr), tamaño(0) {} // Agregar elemento al final de la cola - O(1) void enqueue(T item) { Nodo* nuevoNodo = new Nodo(item); if (final == nullptr) { // Cola vacía, nuevo nodo es frente y final frente = final = nuevoNodo; } else { // Conectar nuevo nodo al final final->siguiente = nuevoNodo; final = nuevoNodo; } tamaño++; } // Remover y retornar el primer elemento - O(1) T dequeue() { if (isEmpty()) { throw runtime_error("Cola vacía"); } T valor = frente->dato; Nodo* temp = frente; frente = frente->siguiente; // Si la cola queda vacía, actualizar final if (frente == nullptr) { final = nullptr; } delete temp; tamaño--; return valor; } // Ver el primer elemento sin removerlo - O(1) T front() { if (isEmpty()) { throw runtime_error("Cola vacía"); } return frente->dato; } // Verificar si la cola está vacía - O(1) bool isEmpty() { return frente == nullptr; } // Obtener el tamaño de la cola - O(1) int size() { return tamaño; } // Mostrar todos los elementos de la cola void mostrar() { Nodo* actual = frente; cout << "Frente: "; while (actual != nullptr) { cout << actual->dato << " "; actual = actual->siguiente; } cout << ":Final" << endl; } // Destructor - libera toda la memoria ~Cola() { while (!isEmpty()) { dequeue(); } } }; // Ejemplo de uso: // Cola<int> miCola; // miCola.enqueue(10); // miCola.enqueue(20); // cout << miCola.dequeue(); // Imprime: 10

🎯 Tipos de Colas:

  • Cola Simple: FIFO básico
  • Cola Circular: El final se conecta con el inicio
  • Cola de Prioridad: Elementos con prioridades
  • Deque: Inserción/eliminación en ambos extremos

📋 Aplicaciones prácticas:

  • Sistemas operativos: Cola de procesos
  • Redes: Buffer de paquetes
  • Algoritmos: BFS (Búsqueda en anchura)
  • Servicios: Cola de impresión
  • Simulaciones: Modelado de sistemas
Operación Complejidad Descripción
Enqueue O(1) Inserción al final
Dequeue O(1)* Eliminación del frente
Front/Peek O(1) Acceso al primer elemento
Search O(n) Búsqueda lineal
*O(1) con implementación optimizada (cola circular o lista enlazada)

Comparación y Casos de Uso

×

🔄 Cuándo usar cada estructura:

📋 Usar Listas Enlazadas cuando:
  • El tamaño de los datos es variable
  • Se realizan muchas inserciones/eliminaciones
  • No se necesita acceso aleatorio
  • Se implementan otras estructuras (pilas, colas)
🔄 Usar Colas cuando:
  • Se necesita procesamiento FIFO
  • Manejo de recursos compartidos
  • Algoritmos de búsqueda (BFS)
  • Sistemas de buffering

Implementaciones Avanzadas

×

🚀 Lista Doblemente Enlazada:

Cada nodo tiene punteros tanto al siguiente como al anterior nodo, permitiendo navegación bidireccional.

🔄 Cola Circular:

Optimiza el uso de memoria reutilizando espacios liberados.

⭐ Cola de Prioridad:

Los elementos se procesan según su prioridad, no según el orden de llegada.

Ejercicios Prácticos

×

💪 Problemas para resolver:

🔗 Ejercicios con Listas Enlazadas:
  1. Invertir una lista: Cambiar el orden de los nodos
  2. Detectar ciclos: Usar algoritmo de Floyd (tortuga y liebre)
  3. Encontrar el medio: Técnica de dos punteros
  4. Fusionar listas ordenadas: Combinar manteniendo orden
🔄 Ejercicios con Colas:
  1. Simulador de banco: Atención a clientes por orden de llegada
  2. Buffer de impresión: Gestión de trabajos de impresión
  3. BFS en grafos: Recorrido por niveles
  4. Palíndromo con deque: Verificar palabras palíndromas
